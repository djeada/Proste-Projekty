## About the Project

The classic sliding puzzle game where you arrange 15 numbered tiles in order by sliding them into an empty space. The goal is to arrange the numbers from 1 to 15 in order.

## Requirements

* A modern web browser, such as the most recent versions of Chrome, Firefox, or Safari.
* There are no other libraries or frameworks required.

## Installation

1. Clone or download the repository.
2. Open `src/index.html` in your web browser.

## Usage

1. Click on a tile adjacent to the empty space to slide it.
2. Use arrow keys for keyboard control.
3. Arrange all tiles in numerical order (1-15) with the empty space in the bottom-right corner.
4. Click "New Game" to shuffle and start over.

## Features

* Click or keyboard control for tile movement.
* Move counter to track your progress.
* Visual indication of correctly placed tiles.
* Shuffle function for new game.
