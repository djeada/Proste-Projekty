## About the Project

The popular 2048 puzzle game where you slide numbered tiles on a 4x4 grid to combine them and create a tile with the number 2048. Use arrow keys to move all tiles in one direction.

## Requirements

* A modern web browser, such as the most recent versions of Chrome, Firefox, or Safari.
* There are no other libraries or frameworks required.

## Installation

1. Clone or download the repository.
2. Open `src/index.html` in your web browser.

## Usage

1. Use arrow keys (or swipe on mobile) to move tiles.
2. When two tiles with the same number collide, they merge into one.
3. After each move, a new tile (2 or 4) appears randomly.
4. Try to create the 2048 tile!
5. The game ends when no more moves are possible.

## Features

* Score tracking.
* Best score saved to local storage.
* Game over detection.
* Win detection when reaching 2048.
* Responsive design with touch support.
