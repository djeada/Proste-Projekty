## About the Project

A classic Hangman word guessing game. The computer randomly selects a word from a list, and the player must guess the word letter by letter before running out of attempts.

## Requirements

* A modern web browser, such as the most recent versions of Chrome, Firefox, or Safari.
* There are no other libraries or frameworks required.

## Installation

1. Clone or download the repository.
2. Open `src/index.html` in your web browser.

## Usage

1. The game displays a series of underscores representing the hidden word.
2. Click on the letter buttons to guess a letter.
3. If the letter is in the word, it will be revealed in its correct position(s).
4. If the letter is not in the word, you lose one attempt.
5. Win by guessing all the letters before running out of attempts.

## Features

* Random word selection from a built-in word list.
* Visual feedback for correct and incorrect guesses.
* Game over and win states with option to play again.
* Keyboard support for letter input.

## Possible improvements

Some of the ideas include:

* Add difficulty levels with different word lengths.
* Add custom word lists or categories.
* Add visual hangman drawing that progresses with each wrong guess.
