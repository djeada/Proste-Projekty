## About the Project

A classic Minesweeper game where players uncover cells on a grid while avoiding hidden mines. Each revealed cell shows the number of adjacent mines, helping the player deduce safe cells.

## Requirements

* A modern web browser, such as the most recent versions of Chrome, Firefox, or Safari.
* There are no other libraries or frameworks required.

## Installation

1. Clone or download the repository.
2. Open `src/index.html` in your web browser.

## Usage

1. Left-click on a cell to reveal it.
2. Right-click on a cell to place or remove a flag.
3. Numbers indicate how many mines are adjacent to that cell.
4. Reveal all non-mine cells to win.
5. Revealing a mine ends the game.

## Features

* Customizable grid size and number of mines.
* Flag placement for suspected mines.
* Auto-reveal of empty adjacent cells.
* Timer and mine counter.
* Win/lose detection.
