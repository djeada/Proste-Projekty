## About the Project

A classic Tic-Tac-Toe game that can be played in two-player mode or against a simple AI opponent. Players take turns placing their symbols (X or O) on a 3x3 grid, trying to get three in a row.

## Requirements

* A modern web browser, such as the most recent versions of Chrome, Firefox, or Safari.
* There are no other libraries or frameworks required.

## Installation

1. Clone or download the repository.
2. Open `src/index.html` in your web browser.

## Usage

1. Select game mode: Two Players or vs Computer.
2. Click on any empty cell to place your symbol.
3. The first player to get three symbols in a row (horizontal, vertical, or diagonal) wins.
4. Click "New Game" to start a new round.

## Features

* Two-player mode.
* Single player mode against AI.
* Score tracking for both players.
* Visual indication of winning line.
* New game and reset functionality.
